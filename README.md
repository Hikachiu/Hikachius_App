# Hikachius_App
ワイのアプリケーション開発用リポジトリ。各ブランチごとにAppは別になってるでな

## アプリ一覧

| ブランチ | アプリ | 概要 |
|---|---|---|
| `app/boatrace` | 競艇予測 | 出走表と過去成績（天候・気温・風・波）から各艇の上位率を出し、買い目をおすすめするWebアプリ |

## ブランチ運用

- `main` … このアプリ一覧だけを置く。コードは置かない。
- `app/<名前>` … 1アプリ = 1ブランチ。**独立ブランチ（orphan）** なので、他のアプリとファイルも履歴も混ざらない。
- 1つのアプリの中で大きめの機能を作るときは `app/<名前>/<機能>` で切って、終わったら `app/<名前>` にマージする。

### 新しいアプリを始める

```bash
git switch --orphan app/新アプリ名
```

最初のコミットをしたら、この README の表に1行足しておく。

### アプリを切り替える

```bash
git switch app/boatrace
```

### 複数のアプリを同時に開く（worktree）

ブランチを切り替えずに、別フォルダに並べて開ける。

```bash
git worktree add ../Hikachius_boatrace app/boatrace
```
